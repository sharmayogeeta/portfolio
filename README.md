| Page | File |
|---|---|
| Home — introduction, basic details, contact | `index.html` |
| My Work — overview of everything below | `work.html` |
| Web articles — searchable, filterable, paginated | `articles.html` |
| Academic publications | `publications.html` |
| Books | `books.html` |

## Updating content
- **Add a web article:** edit `assets/js/articles-data.js` and copy an existing block (url, title, domain, tags).
- **Add a paper:** copy an `<article class="pub">` block in `publications.html`; put any PDF in `pdfs/`.
- **Add a book:** copy an `<article class="book">` block in `books.html`; put the cover in `assets/img/books/`.

Shared styles live in `assets/css/site.css` and scripts in `assets/js/site.js`.
